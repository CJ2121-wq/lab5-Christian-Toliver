# lab5-Christian-Toliver
1. Ambient lighting is a basic amount of light that affects the entire object, even parts that are not directly facing the light.

2. Diffuse lighting is light that depends on the angle between the surface and the light direction.

3. Normal vectors are needed because they describe which direction each surface is facing.

4. The dot product is used to measure how directly a surface faces the light. 

5. Changing the light direction changes which faces of the object appear bright or dark.

6. Changing the light color changes the overall appearance and mood of the object and can make the scene look more or less realistic.

7. The day and night effect was the most interesting modification because it made the cube shift between brighter and darker lighting conditions.

8. Game engines automate lighting calculations because doing all of the lighting math manually for every object and light would be difficult and time-consuming.
